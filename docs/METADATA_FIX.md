# Run Metadata Generation Fix

## Issue

The `run_metadata.json` file was not being created during benchmark runs, causing the pipeline's output scan to report "Metadata: ✗ Not found".

## Root Cause

The `run_timing_sweep.py` script was not saving run metadata to a JSON file, even though the pipeline expected it.

## Solution

### 1. Added Metadata Generation to `run_timing_sweep.py`

Added code after the rank-PID mapping to create and save `run_metadata.json`:

```python
# Save run metadata
import socket
from datetime import datetime

metadata = {
    'benchmark': args.benchmark,
    'ranks': args.ranks,
    'min_size_bytes': min_size,
    'max_size_bytes': max_size,
    'iterations': args.iterations,
    'warmup_iterations': args.warmup,
    'timestamp': datetime.now().isoformat(),
    'hostname': socket.gethostname(),
    'output_directory': output_dir,
    'command': f"python3 run_timing_sweep.py {args.benchmark} --ranks {args.ranks} --min-size {args.min_size} --max-size {args.max_size} --iterations {args.iterations} --warmup {args.warmup}"
}

metadata_file = os.path.join(output_dir, 'run_metadata.json')
with open(metadata_file, 'w') as f:
    json.dump(metadata, f, indent=2)
print(f"Saved run metadata: {metadata_file}")
```

### 2. Created `regenerate_metadata.py` Script

Created a utility script to regenerate metadata for existing run directories:

**Features:**
- Scans all run directories matching pattern `run_*_202*`
- Extracts benchmark name and timestamp from directory name
- Infers run parameters from existing files:
  - Ranks: counted from `all_rank*.csv` files
  - Size range: parsed from benchmark output
  - Iterations: parsed from benchmark output
  - Warmup: parsed from benchmark output
- Creates `run_metadata.json` with all inferred information
- Skips directories that already have metadata
- Supports `--dry-run` for preview

**Usage:**
```bash
# Regenerate metadata for all runs
python3 scripts/regenerate_metadata.py

# Specify custom data directory
python3 scripts/regenerate_metadata.py --data-dir /path/to/data

# Dry run to see what would be done
python3 scripts/regenerate_metadata.py --dry-run
```

  "command": "python3 run_timing_sweep.py all_reduce --ranks 8 --min-size 8 --max-size 1G --iterations 100 --warmup 5"

For regenerated metadata, an additional field is added:
```json
{
  "note": "Metadata regenerated by regenerate_metadata.py"
}
```
